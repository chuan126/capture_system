## 维护要求

- 当前实现、目标设计和历史验证必须明确区分。
- 公共 Topic、WebSocket 字段、页面任务语义或启动脚本变化时，同步更新对应文档。
- 参数文档必须写明单位、坐标系、默认值和无效行为。
- 实机结果必须注明日期、硬件、配置和测试条件。
- 第三方目录中的上游文档不按项目口径改写。
