# 系统状态网页协议

核对日期：2026-08-06

## 1. 边界

浏览器通过同源 WebSocket `/ws/v1/system-status` 接收
`/capture/system/diagnostics` 的最新快照。`system_monitor` 产生状态事实和严重度，
后端只映射字段并检查整条流超时，前端负责显示和连接灯判断。

## 2. 连接状态

WebSocket 状态为 `waiting`、`streaming`、`degraded` 或 `ros_unavailable`。后端在
统一诊断超过 3 秒未更新时发送 `degraded`。前端在快照超过 5 秒时主动清空旧值。

## 3. 快照

```json
{
  "type": "system_status_snapshot",
  "sequence": 25,
  "emitted_at_ns": 1785740000000000000,
  "lidar": {"state": "ok", "message": "雷达已接入", "values": {"online_publishers": "1"}},
  "rtk": {"state": "warn", "message": "串口未连接，正在重试", "values": {"age_ms": "36.00"}},
  "controller": {"state": "ok", "message": "运行正常", "values": {"cpu_percent": "21.00"}},
  "storage": {"state": "ok", "message": "存储正常", "values": {"available_bytes": "92929818624", "writable": "true"}}
}
```

设备 `state` 为 `ok`、`warn`、`error`、`stale` 或 `unknown`。`values` 保留
`DiagnosticStatus` 中的字符串值。

## 4. 连接灯规则

前端不把所有 `warn` 状态解释为已连接。

- 雷达：`state=ok` 且 `online_publishers > 0`；
- RTK：需要有效系统状态流、RTK 诊断为可连接状态，且消息不包含未连接、断开、
  等待、超时或重试语义；
- 主控板：收到有效控制器诊断即表示本机监控可用，高负载告警不等同于断开；
- 数据存储：需要数据目录所在文件系统可写；
- 快照超时或 WebSocket 断开：全部恢复红灯或检查中。

雷达状态只表达厂商 SDK 成功接入设备，不评价点云频率和数据质量。
