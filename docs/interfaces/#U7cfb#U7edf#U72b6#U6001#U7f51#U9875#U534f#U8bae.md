# 系统状态网页协议

## 1. 边界

浏览器通过FastAPI同源WebSocket`/ws/v1/system-status`接收
`/capture/system/diagnostics`的最新快照。状态事实由`system_monitor`统一产生，
后端只映射字段并检查整条诊断流是否超时，前端只负责文字、颜色和GiB换算。

## 2. 连接状态

连接状态消息的`state`可为`waiting`、`streaming`、`degraded`或
`ros_unavailable`。统一诊断超过3秒没有更新时发送`degraded`，浏览器不得继续将
旧快照显示为正常。

## 3. 快照

```json
{
  "type": "system_status_snapshot",
  "sequence": 25,
  "emitted_at_ns": 1785740000000000000,
  "lidar": {"state": "ok", "message": "雷达已接入", "values": {"online_publishers": "1"}},
  "rtk": {"state": "warn", "message": "串口未连接，正在重试", "values": {"age_ms": "36.00"}},
  "controller": {"state": "ok", "message": "运行正常", "values": {"temperature_celsius": "62.00"}},
  "storage": {"state": "ok", "message": "存储正常", "values": {"available_bytes": "92929818624"}}
}
```

设备`state`可为`ok`、`warn`、`error`、`stale`或`unknown`。数值保留为
`DiagnosticStatus.values`中的十进制字符串；容量换算只用于显示，判断阈值仍以ROS
节点发布的严重度为准。

雷达项只表达厂商SDK是否发现并成功接入设备，不表达点云是否发布、频率或数据质量。
