ROS 2 当前已实现的自定义消息只有：

- `interfaces/msg/RtkStatus.msg`；
- `interfaces/msg/ClearanceResult.msg`。

任务创建、查询、逻辑删除和历史测量读取已经实现为 FastAPI HTTP 接口。ROS 2 任务状态、任务事件、记录状态、Service 和 Action 仍是设计项，没有生成接口文件。
详细 Topic 状态见 [ROS 2 架构](../architecture/ROS2架构.md)。

公共接口必须说明版本、字段单位、坐标系、时间戳来源、无效行为和兼容策略。
