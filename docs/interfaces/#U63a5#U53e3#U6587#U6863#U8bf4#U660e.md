ROS 2 当前已实现 RTK、净空、任务状态、记录状态以及任务和记录控制 Service。任务创建、
时间编号、历史查询、逻辑删除、本地数据清理和报告选择由 FastAPI 与中央 SQLite 管理；单任务
开始、暂停、继续和停止由 FastAPI 转发到 ROS 2 `task_manager`。浏览器不直接访问 ROS 2。

详细 Topic 状态见 [ROS 2 架构](../architecture/ROS2架构.md)。
