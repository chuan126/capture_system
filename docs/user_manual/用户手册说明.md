# 采集首页操作说明

适用版本：`0.2.0`

核对日期：2026-08-06

本文说明当前浏览器界面可见功能。任务控制仍是前端原型，不能替代设备端正式任务
状态机。

## 1. 打开页面

完成设备构建并运行：

```bash
cd /home/cat/Project/capture_system
scripts/operation/run_lan_preview.sh
```

在同一局域网电脑中打开脚本打印的地址。

## 2. 顶部状态区

- 系统状态：根据四类设备诊断显示检查中、正常或告警；
- 净空高度：雷达到当前最低合格顶面的距离，单位 m；
- 当前坐标：有效 RTK fix 的 WGS84 经纬度；
- 预留指标：当前没有业务数据；
- 雷达、RTK、主控板和数据存储：绿色灯表示有明确连接或有效诊断证据，红色灯
  表示未连接、数据超时或证据不足。

没有接入雷达或 RTK 时，对应状态灯应为红色。主控板和存储是本机资源，即使外部
设备没有接入，也可能保持绿色。

## 3. 点云和地图

点云区只提供三维视图。鼠标可旋转、平移和缩放。右上角按钮进入放大显示，按
`Esc`、点击背景或再次点击按钮退出。

地图只在 RTK fix 有效且 RMC 不为 `V` 时增加轨迹点。地图断线或 RTK 失效时保留
最后有效位置。

## 4. RTK 定位卡片

卡片显示卫星数、HDOP/PDOP 和高度。页面没有显示入口坐标或出口坐标。当前数值
只反映 RTK 最新快照，不表示已经通过稳定性验收。

## 5. 创建任务

点击“创建任务”，可添加一行或多行。每行填写：

- 任务编号；
- 隧道名称。

可以复制或删除行。当前页面内任务编号不能重复。保存后数据只存在浏览器内存，
刷新页面会清空。

## 6. 作业参数

任务控制卡片内统一设置：

- 雷达安装高度，单位 m；
- 作业车道，左车道或右车道；
- 高度阈值，单位 m。

这些参数由当前页面中的全部任务共享。采集中和暂停时参数锁定。当前版本没有把参数
传给后端或算法节点，也没有将雷达安装高度自动加入 `lidar_to_top_m`。

## 7. 任务切换和队列

当前任务区显示任务编号、隧道名称、车道和状态。点击“切换任务”打开完整任务列表。
采集中或暂停时不允许切换。

待测任务区只显示其他待执行任务，并单独滚动。底部控制按钮固定在卡片底部，不会
覆盖队列。

## 8. 控制按钮

- 开始采集：需要当前任务、合法参数，以及雷达、RTK、存储均显示已连接；
- 暂停：把浏览器内任务状态改为已暂停；
- 继续：把已暂停状态改回采集中；
- 停止：确认后把任务状态改为已停止。

上述按钮目前只改变页面状态，不会启动、暂停或停止 ROS 2 采集节点。现场正式使用前
必须完成设备端任务管理接入。

## 9. 数据回放和报告导出

数据回放页面没有接入任务数据库。报告导出页面使用模拟任务和测试 TXT 文件，仅用于
验证浏览器下载。不得把测试文件作为正式测量结果。

## 10. 常见问题

### 设备未接入但状态灯曾显示绿色

当前版本已改为显式连接证据，并在系统诊断快照超过 5 秒时清空旧状态。若仍出现，
检查浏览器缓存是否加载了旧静态文件，并确认 FastAPI 实际托管的是最新
`frontend/out/`。

### 当前坐标显示 `--`

可能原因包括 RTK WebSocket 未连接、没有 fix、RMC 为 `V` 或快照字段为空。

### 开始采集按钮不可用

依次检查当前任务、雷达安装高度、高度阈值，以及雷达、RTK、数据存储状态灯。
当前前端原型要求三项设备条件同时满足。
