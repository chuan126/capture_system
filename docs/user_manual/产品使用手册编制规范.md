# 产品使用手册编制与截图规范

核对日期：2026-08-30

## 1. 适用范围

本规范用于维护《车载隧道净空高度测量系统产品使用手册》。手册面向一线操作人员，正文以完成一次安全、完整的现场作业为主线，不展开ROS 2、FastAPI、SQLite和内部Topic等开发实现。

## 2. 内容编写规范

- 正文、标题、链接、图注、页眉和页脚统一使用黑色字体；表格底纹和分隔线使用中性灰色；
- 界面名称、按钮名称和状态名称必须与当前客户版页面完全一致；
- 每项操作优先使用“操作前提、操作步骤、操作结果、注意事项、异常处理”结构；
- 一个编号步骤只表达一个主要动作；
- 参数必须同时给出单位、允许范围、作用和错误设置的影响；
- 不把重复保持记录描述为雷达独立产生的50 Hz测量；
- 不把结构化TXT描述为历史原始点云；
- RTK未确认、无效净空和任务异常不得用上一有效值或推测值补写；
- 危险操作使用“警告”，人身与行车风险使用“危险”；
- 第三方服务申请步骤只引用官方页面，并注明页面和价格可能变化；
- 软件功能变化后同时核对采集首页、数据回放、报告导出、记录端和导出端。

## 3. 截图采集标准

| 项目 | 标准 |
| --- | --- |
| 构建类型 | 使用客户版界面，不显示测试入口和浏览器开发工具 |
| 推荐分辨率 | 1920×1080，设备像素比1，浏览器缩放100% |
| 页面状态 | 等待任务、统计、点云和地图完成当前首屏加载后截图 |
| 数据 | 可使用已结束的示例任务，不启动、停止或删除客户正式任务 |
| 敏感信息 | Wi-Fi名称、密码、API Key、安全密钥、客户坐标和其他凭据必须替换或遮蔽 |
| 文件格式 | 页面截图使用PNG；网络图和编号覆盖层使用SVG |
| 文件命名 | `图<章节>-<序号>_中文名称.png`或`.svg` |
| 原图保留 | 标注图引用同目录原始PNG；交付前检查所有引用均可离线显示 |
| Word兼容 | 生成DOCX时必须把SVG引用的底图与标注层合成为单张不透明PNG，不得让Word继续解析外部图片引用 |

## 4. 截图标注标准

- 页面全景图使用红色实心圆、白色数字和白色描边；
- 同一张图中的编号按从左到右、从上到下或实际操作顺序排列；
- 一张图原则上不超过8个编号；
- 编号不得遮挡按钮名称、关键数值和状态；
- 编号含义在图注和紧随其后的表格中解释；
- 输入弹窗、Wi-Fi、高德设置等单一操作截图不强制增加编号；
- 不在截图内部放大段说明文字。

当前标注样式：圆形填充`#e5484d`、白色4 px描边、白色粗体数字。全景图以1920×1080为基准。

## 5. 图号与引用

- 图号按正文章节编号，例如“图4-1 采集首页区域标注”；
- 正文先引用图片，再给出图注；
- 图注使用“图号＋名称＋编号解释”；
- 同一图片只保留一个正式图号；局部裁剪图应使用新的顺序号；
- 删除或新增图片后，应从该章起检查全部图号和正文引用。

## 6. 交付文件

手册维护源文件为`产品使用手册.md`，正式派生文件包括：

- `产品使用手册.html`：浏览器审阅版；
- `产品使用手册.pdf`：打印和客户交付版；
- `产品使用手册.docx`：继续补充硬件章节和企业信息的编辑版。

生成命令：

```bash
PYTHONPATH=/path/to/document-dependencies \
python3 tools/export/generate_product_manual.py \
  docs/user_manual/产品使用手册.md
```
