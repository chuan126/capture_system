# 采集首页操作说明

适用版本：`0.2.0`

核对日期：2026-08-07

本文说明当前浏览器界面可见功能。任务创建、开始、暂停、继续、停止、回放和导出
均通过FastAPI接入设备端。浏览器不直接访问ROS 2。

## 1. 打开页面

完成设备构建并运行：

```bash
cd /home/cat/Project/capture_system
scripts/operation/run_lan_preview.sh
```

在同一局域网电脑中打开脚本打印的地址。

## 2. 顶部状态区

- 系统状态：根据四类设备诊断显示检查中、正常或告警；
- 净空高度：雷达到当前最低合格顶面的距离，单位 m；
- 当前坐标：有效 RTK fix 的 WGS84 经纬度；
- 预留指标：当前没有业务数据；
- 雷达、RTK、主控板和数据存储：绿色灯表示有明确连接或有效诊断证据，红色灯
  表示未连接、数据超时或证据不足。

没有接入雷达或 RTK 时，对应状态灯应为红色。主控板和存储是本机资源，即使外部
设备没有接入，也可能保持绿色。

## 3. 点云和地图

点云区只提供三维视图。鼠标可旋转、平移和缩放。右上角按钮进入放大显示，按
`Esc`、点击背景或再次点击按钮退出。

地图只在 RTK fix 有效且 RMC 不为 `V` 时增加轨迹点。地图断线或 RTK 失效时保留
最后有效位置。

## 4. RTK 定位卡片

卡片显示卫星数、HDOP/PDOP 和高度。页面没有显示入口坐标或出口坐标。当前数值
只反映 RTK 最新快照，不表示已经通过稳定性验收。

## 5. 创建任务

点击“创建任务”打开录入窗口。每行只填写：

- 隧道编号；
- 隧道名称。

窗口支持添加、复制和删除行。提交后 FastAPI 为每条任务生成稳定 UUID 和创建时间显示编号，例如 `20260807_145601`。同一秒批量创建多条任务时，后续任务使用 `20260807_145601_02`、`20260807_145601_03`。浏览器不自行生成正式编号。

删除历史任务不会影响后续任务编号。刷新页面、重启 FastAPI 或重新启动设备后，任务仍从 SQLite 中读取。同一隧道编号允许创建多次检测任务。

## 6. 作业参数

任务控制卡片内统一设置：

- 雷达安装高度，单位 m；
- 作业车道，左车道或右车道；
- 高度阈值，单位 m。

这些参数由当前页面中的全部待执行任务共用。点击开始时，作业车道、雷达安装高度和
高度阈值由设备端冻结并保存。采集中、暂停和控制过渡阶段参数锁定。雷达安装高度
仍不会自动加入`lidar_to_top_m`。

## 7. 任务切换和队列

当前任务区显示创建时间编号、隧道名称、车道和状态。点击“切换任务”打开完整任务列表。
采集中或暂停时不允许切换。

待测任务区只显示其他待执行任务，并与作业参数、当前任务共用卡片中部滚动区域。
底部控制按钮固定在卡片底部，不会覆盖队列。

## 8. 控制按钮

- 开始采集：单击后立即调用设备端任务状态机，不显示确认弹窗。流程依次显示雷达
  初始化、入口RTK记录、记录文件创建和正式记录；
- 暂停：停止正式50 Hz样本写入，实时点云、净空和RTK展示继续；
- 继续：关闭暂停区间并恢复正式样本写入；
- 停止：单击后立即固定停止时间，不显示确认弹窗。自动记录出口RTK快照，完成数据库
  收尾后显示已停止，并按创建时间自动选择下一项待执行任务。系统不会自动开始下一任务。

开始不等待雷达或RTK真实数据检查。入口RTK没有有效坐标时显示“入口RTK坐标未确认”，
任务仍继续。出口RTK没有有效坐标时同样完成停止，报告对应坐标保持空值。

任务控制通过`/ws/v1/task-status`更新。浏览器刷新或断线不会停止设备端任务，重新打开
页面后会恢复持久状态。准备、暂停、继续或停止阶段超时后，设备端会自动恢复到安全状态。
若仍显示活动任务卡住，可使用“停止”或“恢复控制”，不需要重新启动系统。

## 9. 数据回放和报告导出

数据回放页面直接列出全部任务，并按创建日期分组。存在测量文件时，页面读取完整高度序列、无效断点、统计结果、检测车道和入口出口 RTK。没有测量文件时保持空状态。

“删除任务”执行逻辑删除，只把任务从三个页面的普通列表中移除，不负责释放测量文件空间。需要释放设备存储空间时，在数据回放页勾选任务，或者点击日期分组中的“选择当日”，再执行“清理所选数据”。系统物理删除所选任务目录中的 `measurements.db` 和单任务导出文件，同时保留任务索引、时间编号、状态和清理时间。活动任务不能清理。

TXT 面向当前任务。PDF 面向报告页中勾选的一个或多个任务，不再要求先建立或结束作业批次。导出按钮只对正常完成、来源为正式记录、记录完整且包含有效高度样本的任务有效。设备端记录器按 50 Hz 写入最近源帧保持序列，TXT 包含源帧序号、源帧年龄、重复标志和重复序号。界面测试数据不得作为正式测量结果。

## 10. 常见问题

### 设备未接入但状态灯曾显示绿色

当前版本已改为显式连接证据，并在系统诊断快照超过 5 秒时清空旧状态。若仍出现，
检查浏览器缓存是否加载了旧静态文件，并确认 FastAPI 实际托管的是最新
`frontend/out/`。

### 当前坐标显示 `--`

可能原因包括 RTK WebSocket 未连接、没有 fix、RMC 为 `V` 或快照字段为空。

### 开始采集按钮不可用

检查当前任务、雷达安装高度、高度阈值和任务控制Service状态。雷达、RTK状态灯不会
阻止开始。若显示任务控制不可用，检查`task_manager`和`data_recorder`是否已经启动。

### 入口或出口RTK显示坐标未确认

该状态表示按钮操作时没有可用RTK快照。任务不会因此暂停或等待。检查RTK串口和定位
状态，后续任务仍可继续执行。报告中缺失端点坐标保持空值。
