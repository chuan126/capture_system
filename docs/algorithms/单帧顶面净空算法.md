# 单帧顶面净空算法

实现位置：`ros2_ws/src/clearance_engine`

核对日期：2026-08-21

## 1. 测量量

输出 `lidar_to_top_m` 表示雷达原点到当前帧最低可信平面或局部曲面的竖直距离。

```text
最终路面净空 ≠ lidar_to_top_m
```

最终路面净空至少还需要雷达安装高度、路面模型、车辆姿态和标定信息。当前前端显示的
“净空高度”仍使用该雷达到顶面的距离。

## 2. 输入输出

```text
/capture/lidar/points_compensated_enu
→ clearance_engine_node
→ /capture/clearance/result
```

输入必须使用 `frame_id=lidar_local_enu`。第三轴必须稳定为 Up，两个水平轴不要求
严格对应地理东、北。

## 3. 平面处理流程

```text
顶部角度 ROI
→ 体素降采样
→ 近水平面 RANSAC
→ 原始分辨率内点恢复
→ 二维网格连通区域划分
→ PCA 重新拟合
→ 倾角和残差检查
→ 计算区域内最低平面高度
```

RANSAC 只在降采样点上搜索模型。最终平面参数、质量和最低高度使用原始分辨率点。
不合格候选面被移除后继续搜索，避免主体顶面阻止较低障碍物进入候选集。

该流程仍由 `clearance_estimator.cpp` 实现，RANSAC 模型、坐标转换、原始分辨率内点
恢复、网格连通、PCA 重拟合和高度计算没有因曲面能力改变。

## 4. 曲面处理流程

```text
同一补偿后点云
→ 同一顶部 ROI
→ 5 cm体素降采样及少于10000点限量
→ K近邻法向量估计
→ 法向夹角与曲率约束的Region Growing
→ Cluster局部二次曲面最小二乘
→ 残差、跨度、占用网格、法向和曲率检查
→ 只在实际占用网格内搜索最低曲面高度
```

局部二次模型使用：

```text
U(E,N) = aE² + bEN + cN² + dE + eN + f
```

拟合前对 `E/N` 减去 Cluster 中心以改善数值条件，使用 Eigen 列主元 QR 求解六个
参数。最低点不使用二次函数的全局极值，也不遍历包围盒空白区域；只把 Cluster
实际占用网格中心代入模型，避免拱顶数学外推产生虚假低点。

法向估计视点设为雷达原点，因此顶部内表面法向正常应朝向传感器并具有负 `z` 分量。
平均法向明显非向下的 Cluster 被拒绝。PCL 法向曲率 P95、二次模型残差 P95、双向
跨度、点数和占用网格共同形成硬门限与置信度。

## 5. 统一候选与运行策略

原有 `PlaneCandidate` 转换为置信度 1.0 的统一 `SurfaceCandidate`，曲面分支直接输出
`QUADRATIC_SURFACE` 候选。所有候选必须满足 `confidence > surface.min_confidence`，
最终结果为最低可信高度；平面与曲面高度差不超过
`surface.plane_preference_tolerance_m` 时优先平面，保持原有平面结构输出稳定。

每帧始终运行平面检测。曲面分支始终按`surface.update_rate_hz`限频，避免输入异常时
Region Growing每帧满载。平面无效且曲面尚未到更新周期时跳过该帧结果发布。

验证。`clearance_engine.yaml` 和 `clearance_engine_roof_default.yaml` 保留为其他
场景参数，不是当前 Launch 默认值。

## 7. 输出质量字段

`ClearanceResult.ransac_plane_count` 表示本帧 RANSAC 成功生成模型、回到原始分辨率收集内点且达到最少内点要求后进入后续区域分析的**平面模型数量**。它不等于 `ransac.max_candidate_planes`；后者只是循环上限，剩余点不足、模型失败或内点不足时会提前结束。

`ClearanceResult.candidate_count` 表示通过硬质量检查和置信度门限的**统一平面/曲面
候选数量**。一个 RANSAC 平面模型仍可能被二维连通性拆成多个平面候选，因此该字段
与 RANSAC 模型数量不同。

兼容字段 `selected_area_m2` 表示选中区域的**水平投影网格覆盖面积**。平面使用
`region.grid_size_m`，曲面使用 `surface.grid_size_m`；它依赖点云采样密度与网格尺寸，
不应解释为障碍物或顶面的真实几何表面积。

`ClearanceResult` 还发布内点数、倾角、残差、最低位置、有效点比例和处理时间。无效帧必须显示为无效，不沿用上一帧高度。

Debug 日志逐帧提供 `ROI points`、`Plane candidate count`、`Plane accepted`、
`Surface cluster count`、`Surface accepted`、`Final clearance height`、`Selected type`，
并分别记录平面、曲面和总耗时。

## 8. 未覆盖能力

- 路面拟合和路面到顶面的完整净空；
- 车辆通行包络；
- 车道几何约束；
- 跨帧跟踪和任务累计最小值；
- 对风机、标志牌和不同材质障碍物的分类；
- 正式测量不确定度。
