# 单帧顶面净空算法

实现位置：`ros2_ws/src/clearance_engine`

核对日期：2026-08-06

## 1. 测量量

输出 `lidar_to_top_m` 表示雷达原点到当前帧最低合格近水平顶面的竖直距离。

```text
最终路面净空 ≠ lidar_to_top_m
```

最终路面净空至少还需要雷达安装高度、路面模型、车辆姿态和标定信息。当前前端显示的
“净空高度”仍使用该雷达到顶面的距离。

## 2. 输入输出

```text
/capture/lidar/points_compensated_enu
→ clearance_engine_node
→ /capture/clearance/result
```

输入必须使用 `frame_id=lidar_local_enu`。第三轴必须稳定为 Up，两个水平轴不要求
严格对应地理东、北。

## 3. 处理流程

```text
顶部角度 ROI
→ 体素降采样
→ 近水平面 RANSAC
→ 原始分辨率内点恢复
→ 二维网格连通区域划分
→ PCA 重新拟合
→ 倾角和残差检查
→ 计算区域内最低平面高度
→ 选择最低合格候选面
```

RANSAC 只在降采样点上搜索模型。最终平面参数、质量和最低高度使用原始分辨率点。
不合格候选面被移除后继续搜索，避免主体顶面阻止较低障碍物进入候选集。

## 4. 当前默认启动配置

`bringup/clearance_preview.launch.py` 默认加载：

```text
clearance_engine/config/clearance_engine_small_board_1cm.yaml
```

该配置与 `clearance_engine.yaml` 的高速风机初始参数不同。主要参数为：

| 参数 | 默认值 |
| --- | ---: |
| 顶部高度范围 | 0.20～15.0 m |
| 水平半角 | 55°、35° |
| 最大平面倾角 | 15° |
| RANSAC 距离门限 | 0.04 m |
| 最大候选平面 | 8 |
| 最少剩余点 | 100 |
| 最少原始内点 | 50 |
| 网格尺寸 | 0.01 m |
| 最小双向跨度 | 5 格 |
| 最少占用网格 | 15 格 |
| 95% 残差门限 | 0.05 m |

1 cm 网格可能在点间距较大时破坏连通性，属于实验配置，必须结合真实障碍物点密度
验证。`clearance_engine.yaml` 和 `clearance_engine_roof_default.yaml` 保留为其他
场景参数，不是当前 Launch 默认值。

## 5. 输出质量字段

`ClearanceResult` 同时发布有效性、无效原因、候选数量、内点数、区域面积、倾角、
残差、最低位置、有效点比例和处理时间。无效帧必须显示为无效，不沿用上一帧高度。

## 6. 未覆盖能力

- 路面拟合和路面到顶面的完整净空；
- 车辆通行包络；
- 车道几何约束；
- 跨帧跟踪和任务累计最小值；
- 对风机、标志牌和不同材质障碍物的分类；
- 正式测量不确定度。
