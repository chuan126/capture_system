# 单任务净空可信度算法

## 1. 适用范围

本算法只使用一个任务的 `measurement.db` 和该任务冻结的算法质量数据。不使用其他任务、往返测量或“物理隧道”聚合结果增强可信度。

算法输出：

- **原始单帧最低值**：所有有效、非重复源帧的直接最小值，不做异常剔除。
- **建议最低可信净空**：由几何合格的多源帧低值带，或受连续性保护的真实低值结构给出。证据不足时为空，不复制原始单帧最低值。
- **可信度**：0–100的证据完整度评分，分为高、中、低和证据不足。它不是统计概率。

## 2. 有效性和低值事件

重复的 `source_sequence`、设备判无效、非有限/非正高度和全零最低点不参与最低值计算。空间距离优先由里程计位置累计；里程计缺失或跳变时，局部基线退化为有界样本窗口，且不允许自动剔除低值。

低值候选由局部70%分位基线、MAD和0.50 m绝对落差共同判定。相邻候选按行驶距离合并为事件，再使用持续帧数、结构长度、高度MAD、最低点世界轨迹连续性、边界跳变和周期性判为真实结构、待复核或高置信度偶发异常。周期性设施和具有连续空间证据的单个结构受保护。

建议值还会独立建立“任务内可信低值带”。源帧至少要提供3项几何质量字段，并且所有已提供字段均不得越过硬边界：有效点比例不低于0.05、平面内点不少于50、投影面积不小于0.08 m²、倾角不大于15°、残差P95不大于0.05 m。这样普通平缓洞顶不必先相对局部基线下降0.50 m，也能形成建议值；边缘小平面和拟合质量越界帧则只保留在原始最低值中供追溯。

## 3. 可信度证据评分

总分为四类归一化证据的加权和：

```text
score = round(100 × (0.35 × Q + 0.30 × P + 0.20 × S + 0.15 × I))
```

- `Q` 几何质量：有效点比例、选中平面内点数、网格覆盖面积、倾角和残差P95。
- `P` 持续性：独立源帧数、低值结构长度和结构内高度MAD。
- `S` 空间证据：最低点世界轨迹连续性和事件边界点跳变。
- `I` 时间/里程完整性：可靠里程样本占比和净空样本的源帧年龄。

证据缺失不会被当作优质数据，并有以下硬上限：

- 少于3个独立源帧：最高39分。
- 5项平面质量证据中少于3项：最高59分。
- 原始最低值未形成独立低值事件、且又没有形成可信低值带：最高65分。
- 局部距离证据不足或需复核：最高49分。
- 已判为高置信度偶发异常：最高25分。

分级阈值为：高 `≥80`，中 `60–79`，低 `40–59`，证据不足 `<40`。

## 4. 建议值决策

建议值有两条单任务证据路径：

1. 对任务内全部几何合格源帧取低侧5%分位，并使用最低10%且至少5个独立源帧作为可信度证据带；
2. 对被判为真实或周期性保护、且至少包含5个几何合格独立源帧的低值事件取5%分位。

两条路径同时成立时采用更低的结果；数值相同则优先采用具有连续空间证据的低值事件。这样既抑制孤立毛刺，也不会因全任务分位数而漏掉占比很小的真实横梁。

如果连5个几何合格独立源帧都没有，建议最低可信净空输出为空，可信度为“证据不足”，而不是把原始最低值复制成看似经过判断的建议值。报告仍保留原始单帧最低值、异常分析后的有效最低值和可解释原因，不修改 `measurement.db` 中的原始记录。
