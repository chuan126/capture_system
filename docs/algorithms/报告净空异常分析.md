# 报告净空异常分析

核对日期：2026-08-21

正式记录使用50 Hz最近源帧保持序列，并通过来源字段识别重复保持样本；真实源帧另表保存。算法不根据相同高度或
相同最低点去重；只有数据库明确保存了通信层重复标志，或可靠`source_sequence`重复时才
排除重复通信帧。原始SQLite和TXT始终不修改。

## 处理流程

```text
基础有效性检查
→ ODIN三维位置累计里程
→ ±20 m局部70%分位数与MAD基准
→ 低值候选
→ 距离域低值事件聚类
→ 最低点空间轨迹与前后恢复分析
→ 至少3个相似事件的周期性结构保护
→ 可解释评分
→ 原始最低值 / 有效最低值
```

实时高度非有限或不大于0、算法明确无效、最低点XYZ同时为0的记录不参加统计。低值候选
满足`baseline - height > max(0.50 m, 6 * 1.4826 * MAD)`。候选本身不会被删除。

事件状态为`VALID_STRUCTURE`、`PROTECTED_PERIODIC_STRUCTURE`、`REVIEW_REQUIRED`或
`HIGH_CONFIDENCE_OUTLIER`。只有最后一种从`effective_min_clearance`排除；待复核事件仍
保守计入。每次TXT导出都会并列生成`*_异常分析.json`，记录事件里程、局部基准、点云跳变、
周期组、评分、命中规则和最终状态。

## 默认参数

参数集中在`ClearanceAnomalyConfig`，业务逻辑中不散落阈值。

| 参数 | 默认值 | 单位/含义 |
| --- | ---: | --- |
| `local_window_radius_m` | 20.0 | m，局部窗口半径 |
| `local_baseline_quantile` | 0.70 | 局部正常基准分位数 |
| `absolute_drop_threshold_m` | 0.50 | m，绝对下降门限 |
| `mad_multiplier` / `mad_scale` | 6.0 / 1.4826 | MAD稳健门限 |
| `minimum_local_samples` | 9 | 局部最少样本 |
| `minimum_local_span_m` | 8.0 | m，局部最小覆盖长度 |
| `maximum_odometry_step_m` | 10.0 | m，单步里程可靠性门限 |
| `event_merge_gap_m` | 2.0 | m，低值事件合并间距 |
| `flank_search_distance_m` | 5.0 | m，前后正常区搜索距离 |
| `normal_return_tolerance_m` | 0.25 | m，恢复到局部基准容差 |
| `structure_min_samples` | 3 | 单个真实结构最少测量数 |
| `structure_min_length_m` | 0.80 | m，结构有效持续长度 |
| `structure_max_height_mad_m` | 0.15 | m，结构内部高度MAD上限 |
| `short_event_length_m` | 0.30 | m，极短事件门限 |
| `large_drop_m` | 1.00 | m，大幅下降证据门限 |
| `point_boundary_jump_m` | 2.00 | m，边界最低点跳变门限 |
| `world_point_spread_m` | 1.00 | m，最低点世界轨迹绝对容差 |
| `world_point_spread_length_ratio` | 0.25 | 世界轨迹相对事件长度容差 |
| `periodic_min_events` | 3 | 建立周期保护的最少事件数 |
| `periodic_min_spacing_m` | 5.0 | m，最小周期 |
| `periodic_position_tolerance_m` | 1.50 | m，周期位置绝对容差 |
| `periodic_position_tolerance_ratio` | 0.05 | 周期位置相对容差 |
| `periodic_height_tolerance_m` | 0.20 | m，同组最低高度容差 |
| `periodic_lateral_tolerance_m` | 0.50 | m，同组最低点横向容差 |
| `periodic_vertical_tolerance_m` | 0.30 | m，同组最低点垂向容差 |
| `periodic_length_ratio_max` | 2.0 | 同组事件长度最大比值 |
| `review_score_threshold` | 2 | 待复核评分门限 |
| `high_confidence_score_threshold` | 4 | 自动排除评分门限 |

评分权重分别为：孤立`+2`、极短`+2`、大幅下降`+2`、前后立即恢复`+2`、最低点跳变
`+1`、世界轨迹不连续`+2`；多次测量`-1`、有持续长度`-1`、高度稳定`-1`、结构连续
`-2`、周期结构`-4`。

## 样例结果

对`20260821_135821_F05-2_50Hz测量明细 (1).txt`分析时，`3.858 m`事件为样本
959至966，累计里程长度约2.200 m，局部基准约7.476 m，最大下降约3.618 m，最低点
世界轨迹跨度约1.170 m。它命中大幅局部下降、前后立即恢复、边界最低点跳变和世界轨迹
不连续，同时得到多次测量、持续长度和高度稳定的减分，最终评分4，状态为
`HIGH_CONFIDENCE_OUTLIER`。因此它不是因为数值等于3.858 m被特殊删除。

同一文件原始最低净空为3.858 m。排除此高置信事件后，剩余3.923 m事件因位于记录末段，
缺少完整后方恢复证据，被保守标记为`REVIEW_REQUIRED`并继续计入，所以有效最低净空为
3.923 m。现场应结合对应点云复核该事件。
