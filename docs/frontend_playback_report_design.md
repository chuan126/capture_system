# 数据回放与报告导出前端设计说明

核对日期：2026-08-06

## 1. 适用范围

本文说明当前前端已落地的页面结构和接口边界。历史高度记录读取和任务逻辑删除已经接入 FastAPI，正式文件生成尚未实现。

## 2. 页面联动

`Home` 组件通过 FastAPI 的任务 HTTP 接口读取设备端持久化任务列表，并维护当前页面选择的 `selectedTaskId`。采集首页、数据回放和报告导出使用同一批后端任务对象。前端不直接访问 ROS 2。

任务不设置任务名称。FastAPI 创建独立 UUID 作为内部 `taskId`，并在 SQLite 事务中分配 `01`、`02` 等持久化显示序号。任务对象包含隧道编号、隧道名称、状态和记录可用性。页面刷新或 FastAPI 重启后会重新读取任务列表。开始、暂停和停止仍是前端状态原型，尚未写回设备端任务状态。

## 3. 数据回放页面

页面包含以下固定区域：

- 任务上下文和跨页面操作；
- 左侧任务搜索、筛选和选择；
- 中部当前任务的完整 50 Hz 净空高度曲线；
- 右侧隧道信息、测量统计、入口与出口 RTK 和数据质量。

项目不计划在历史回放中保留原始点云、地图轨迹和播放式回放控制。页面中部只展示当前任务的完整高度曲线，支持拖拽平移、滚轮缩放、按钮缩放、键盘左右平移和复位。前端通过 `/api/v1/tasks/{task_id}/measurements` 读取统一时间戳、高度序列、有效性、统计结果和隧道端点 RTK。无效采样在曲线上断开。无有效数据时返回空值和明确原因，前端不用实时流、上一有效值或自动生成曲线补齐。

回放页顶部提供当前任务删除按钮。删除前显示任务编号、隧道信息、任务状态和记录存在性。确认后调用 FastAPI DELETE 接口，成功后从三个页面的共享任务列表移除。

## 4. 报告导出页面

报告页面保留任务选择和两个直接导出区域。

50 Hz 测量明细 TXT 针对当前选中的任务，每条采样记录一行。首版字段至少包括记录时间、隧道编号、检测车道、实时高度、最低高度、隧道入口 RTK 和隧道出口 RTK。记录时间应保留毫秒精度，20 ms 间隔对应 50 Hz。无效高度和无有效定位应保留空值及状态原因。

隧道净空检测汇总 PDF 计划汇总设备任务数据库中的符合条件任务，按自动任务编号逐行列出隧道编号、检测车道、最低高度、记录时间、隧道入口 RTK 和隧道出口 RTK。PDF 不显示任务名称。

任务开始时应保存当时的检测车道，避免报告页读取后来修改的共享车道设置。正式 TXT 和 PDF 文件生成接口已经实现，最低高度由后端从测量数据库中的有效样本计算。入口和出口 RTK 仍依赖测量文件中已有端点记录，设备端自动判定尚未实现。

## 6. 显示适配

数据回放和报告导出页面沿用采集首页的字体、间距、边框和状态表达。净空高度曲线在宽屏中占据主要区域。常规正文和状态文字不低于 11 px，主要字段和控件为 12 至 13 px，页面标题为 19 至 20 px。

在可用宽度不超过 1500 px 时，数据回放右侧统计区移动到曲线下方。在可用宽度不超过 1320 px 时，报告任务列表移至内容上方。移动端改为单列布局。

## 7. 采集首页待测任务可见性

在 CSS 视口宽度为 761 至 1600 px 时，任务控制卡片保持纵向 flex 结构。卡片中部的作业参数、当前任务和待测任务作为唯一纵向滚动区域，卡片标题和底部采集控制区位于滚动区域之外。
