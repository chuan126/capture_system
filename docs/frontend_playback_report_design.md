# 数据回放与报告导出前端设计说明

核对日期：2026-08-06

## 1. 适用范围

本文说明当前前端已落地的页面结构和后续接口边界。当前实现属于界面和状态联动原型，未实现历史高度记录读取和正式文件生成。

## 2. 页面联动

`Home` 组件统一维护本次浏览器会话中的任务列表和当前任务编号。采集首页、数据回放和报告导出均使用同一个 `selectedTaskId`。任务停止后，采集首页当前任务卡片可以直接进入回放或报告页面。

任务不再设置任务名称。系统按创建顺序生成 `01`、`02` 等任务编号。任务对象保留稳定的内部 `taskId`、自动序号、隧道编号、隧道名称、检测车道和状态。页面刷新后任务仍会丢失。

## 3. 数据回放页面

页面包含以下固定区域：

- 任务上下文和跨页面操作；
- 左侧任务搜索、筛选和选择；
- 中部当前任务的完整 50 Hz 净空高度曲线；
- 右侧隧道信息、测量统计、入口与出口 RTK 和数据质量。

项目不计划在历史回放中保留原始点云、地图轨迹和播放式回放控制。页面中部只展示当前任务的完整高度曲线，支持拖拽平移、滚轮缩放、按钮缩放、键盘左右平移和复位。后端只需提供任务元数据、统一时间戳、高度序列、有效性、最低值和隧道端点 RTK。无效采样在曲线上断开。无有效数据时返回空值和明确原因，前端不得用实时流、上一有效值或模拟曲线补齐。

## 4. 报告导出页面

报告页面保留任务选择和两个直接导出区域。

50 Hz 测量明细 TXT 针对当前选中的任务，每条采样记录一行。首版字段至少包括记录时间、隧道编号、检测车道、实时高度、最低高度、隧道入口 RTK 和隧道出口 RTK。记录时间应保留毫秒精度，20 ms 间隔对应 50 Hz。无效高度和无有效定位应保留空值及状态原因。

隧道净空检测汇总 PDF 汇总当前会话中的全部任务，按自动任务编号逐行列出隧道编号、检测车道、最低高度、记录时间、隧道入口 RTK 和隧道出口 RTK。PDF 不显示任务名称。

任务开始时保存当时的检测车道，避免报告页读取后来修改的共享车道设置。正式记录、最低高度、隧道端点识别和文件导出接口仍未实现，TXT 和 PDF 按钮保持禁用。

## 6. 显示适配

数据回放和报告导出页面沿用采集首页的字体、间距、边框和状态表达。净空高度曲线在宽屏中占据主要区域。常规正文和状态文字不低于 11 px，主要字段和控件为 12 至 13 px，页面标题为 19 至 20 px。

在可用宽度不超过 1500 px 时，数据回放右侧统计区移动到曲线下方。在可用宽度不超过 1320 px 时，报告任务列表移至内容上方。移动端改为单列布局。

## 7. 采集首页待测任务可见性

在 CSS 视口宽度为 761 至 1600 px 时，任务控制卡片保持纵向 flex 结构。卡片中部的作业参数、当前任务和待测任务作为唯一纵向滚动区域，卡片标题和底部采集控制区位于滚动区域之外。
