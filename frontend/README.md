# 隧道净空测量显控终端前端

核对日期：2026-08-06

前端使用 Next.js、React 和 Three.js，设备构建输出为静态文件，由 FastAPI 同端口
托管。当前导航包含采集首页、数据回放和报告导出。独立任务管理页面已经删除。

## 1. 采集首页

### 1.1 顶部系统状态

顶部左侧显示系统总状态，并提供三张摘要卡片：

- 净空高度：显示 `lidar_to_top_m`，即雷达到当前最低合格顶面的距离；
- 当前坐标：仅在 RTK WebSocket 正常、fix 有效且 RMC 不为 `V` 时显示 WGS84
  经纬度；
- 预留指标：保留后续业务扩展。

顶部右侧以 2×2 排列雷达、RTK、主控板和数据存储。连接灯使用明确设备证据判断，
绿色表示已连接，红色表示未连接或诊断流超时。前端不会把 `warn` 一律解释为连接。
系统状态快照超过 5 秒未更新时清空旧值。

### 1.2 点云和地图

点云预览通过 `/ws/v1/cloud-preview` 接收 PCV1 二进制帧，只提供三维交互视图。
坐标语义固定为局部东北天，`x=East`、`y=North`、`z=Up`。页面不再提供沿 X 轴
俯视或断面视图，也不显示旧的底部坐标状态栏。

点云和高德地图均提供右上角放大按钮。放大时使用页面遮罩，并支持再次点击、点击
遮罩或按 `Esc` 退出。

高德地图使用 `/ws/v1/rtk` 的有效 WGS84 坐标，在前端转换为 GCJ-02。无定位或
RMC 明确无效时保留最后有效地图位置，不新增轨迹点。

### 1.3 RTK 定位卡片

RTK 卡片保持紧凑，只显示：

- 卫星数；
- HDOP / PDOP；
- 高度。

入口坐标和出口坐标未在当前页面显示。进出洞稳定窗口尚未实现，前端不得用当前
fix 伪造入口或出口结论。

### 1.4 任务控制卡片

任务控制是前端交互原型，当前不连接设备端任务状态机。

卡片结构：

1. 作业参数栏：雷达安装高度、作业车道和高度阈值，所有浏览器内任务共用；
2. 当前任务：自动任务编号、隧道编号、隧道名称、车道和文字状态；
3. 待测任务：随卡片中部内容自然增长，由任务控制卡片中部统一滚动；
4. 固定控制区：开始采集、暂停或继续、停止。

“创建任务”弹窗支持一次录入一条或多条隧道记录，只填写隧道编号和隧道名称。任务编号由系统按创建顺序自动生成并显示为 `01`、`02` 等。采集和暂停时共享参数及任务切换被锁定。

任务状态只有 `待执行`、`采集中`、`已暂停` 和 `已停止`。页面刷新后任务全部清空。
按钮只改变 React 内存状态，不会启动、暂停或停止 ROS 2 节点。正式任务控制必须在
实现 `task_manager` 和后端控制接口后重新接入。

### 1.5 净空曲线

`/ws/v1/clearance` 提供单帧算法结果。页面保留最近 120 帧，遇到无效帧时曲线断开，
不会沿用旧值。`lidar_to_top_m` 仍是雷达到顶面的距离，不是最终路面净空。

## 2. 数据回放和报告导出

两个页面已按任务上下文重新设计，并与采集首页共享本次浏览器会话中的任务列表和
当前任务选择。任务停止后，采集首页当前任务卡片提供“查看数据”和“报告检查”入口。

### 2.1 数据回放

页面结构包括：

- 左侧任务搜索、状态筛选和任务选择；
- 中部当前任务的 50 Hz 净空高度曲线、时间控制和事件区间；
- 右侧隧道信息、测量统计、入口与出口 RTK 和数据质量。

当前没有正式任务高度记录和统一时间索引接口，数值显示为空值。数据回放页面只展示单个任务的完整净空高度曲线，不保留点云、地图、播放按钮、逐点跳转或进度条。曲线组件支持拖拽平移、滚轮缩放、按钮缩放、键盘平移和双击复位；无效采样保持断线。页面不会使用实时 WebSocket 或模拟曲线替代历史记录。

### 2.2 报告导出

页面保留两种直接导出格式。

1. 50 Hz 测量明细 TXT。每个有效采样时刻一行，字段至少包括记录时间、隧道编号、检测车道、实时高度、最低高度、隧道入口 RTK 和隧道出口 RTK；
2. 隧道净空检测汇总 PDF。按自动任务编号逐行列出隧道编号、检测车道、最低高度、记录时间、隧道入口 RTK 和隧道出口 RTK。

正式记录、任务最低值、隧道端点识别和导出接口尚未实现，因此两个导出按钮保持禁用。
页面只展示字段结构和当前浏览器会话中的真实任务元数据，不计算或补造高度、时间和坐标。

## 3. WebSocket

| 地址 | 前端组件 | 内容 |
| --- | --- | --- |
| `/ws/v1/cloud-preview` | `PointCloudViewer` | PCV1 局部东北天点云 |
| `/ws/v1/clearance` | `useClearanceSocket` | 单帧净空结果 |
| `/ws/v1/rtk` | `useRtkSocket` | RTK 状态和 fix |
| `/ws/v1/system-status` | `useSystemStatusSocket` | 四类系统诊断 |

## 4. 高德配置

页面可在“地图设置”中填写 Web 端 Key 和 `securityJsCode`，配置保存在当前浏览器的
`localStorage`。构建时也可以提供：

```bash
NEXT_PUBLIC_AMAP_KEY=你的Web端Key
NEXT_PUBLIC_AMAP_SECURITY_CODE=你的securityJsCode
```

正式部署应在高德控制台限制允许访问的域名，不应把无限制密钥用于现场设备。

### 回放与报告页面显示尺度

数据回放和报告导出页面已针对 16 寸笔记本提高文字、图标和控件尺寸。页面会根据 CSS 视口宽度调整列布局。报告页面在中等宽度下使用上下排列，回放检查区在较窄桌面宽度下移动到主视图下方。该调整不改变采集首页布局和实时数据协议。

### 采集首页显示尺度

采集首页已采用与数据回放、报告导出一致的笔记本可读性标准。系统状态、实时测量、设备状态、RTK 指标、任务参数、任务列表和采集控制的常规文字提高到 10 至 12 px，主要测量值和任务编号保持更大的视觉层级。点云、地图和曲线区域的标题、状态标签、坐标提示、图表刻度及放大按钮同步增大。

当 CSS 视口宽度为 1181 至 1440 px 时，采集首页改为纵向滚动布局。点云与地图仍保持同一行，RTK 与任务控制移动到主测量区下方。任务控制卡片使用明确的视口相关高度，卡片中部统一滚动，标题和底部采集控制保持可见。宽度不超过 1180 px 时继续使用窄屏布局，并保留既有字体和控件尺寸。
