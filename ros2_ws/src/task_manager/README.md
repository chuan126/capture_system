该目录目前只有职责说明，没有 `package.xml`、`CMakeLists.txt`、节点、消息、Service、
Action 或测试。

目标职责是成为设备端任务状态的唯一权威来源，管理任务创建、参数冻结、开始、暂停、
继续、停止、故障和收尾。浏览器任务控制不得长期保留独立状态机。

当前采集首页的任务创建和按钮只改变 React 内存状态，页面刷新后丢失，也不会控制
ROS 2 节点。实现本包时至少需要同步完成：

- 任务标识和配置快照；
- 任务状态消息；
- 创建和查询接口；
- 长任务控制 Action 或等价设备端机制；
- 暂停、继续、停止和异常收尾语义；
- 与 `data_recorder`、FastAPI 和前端的联合测试。
