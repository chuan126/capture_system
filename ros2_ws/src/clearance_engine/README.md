# clearance_engine

该包对单帧补偿点云执行顶部区域过滤、多候选近水平面提取、连通区域复核和最低高度计算。目标是以雷达约10 Hz的输出频率检测当前车道或相邻车道上方的风机底层平面。

## 输入与输出

输入为

```text
/capture/lidar/points_compensated_enu
```

点云字段为`x=局部水平轴1`、`y=局部水平轴2`、`z=Up`。水平轴不要求严格对应真实地理东、北，第三轴必须稳定为Up。

输出为

```text
/capture/clearance/result
```

`lidar_to_top_m`表示雷达原点到本帧最低合格平面的竖直距离。若要得到路面净空，还需加入雷达安装高度。

## 单帧处理流程

```text
补偿后的单帧点云
→ 1至10 m顶部ROI和全车道宽角度ROI
→ 4 cm体素降采样
→ RANSAC搜索近水平候选平面
→ 回到原始分辨率ROI收集平面内点
→ 3 cm网格八邻域连通区域
→ 区域内全部点PCA重新拟合
→ 倾角和95%残差检查
→ 计算实际占用网格内的最低平面高度
→ 最多继续提取4个平面
→ 选择最低合格平面
```

RANSAC仅使用降采样点云搜索模型。最终平面参数、残差和最低高度仍由原始分辨率点计算。

当当前最大平面没有通过区域尺寸或质量检查时，程序会删除该平面内点并继续搜索，不再提前停止。该处理用于避免主体顶面或其他结构阻止后续风机底层平面进入候选集。

## 默认参数

```text
顶部高度范围       1.0至10.0 m
水平半角           两个水平轴均为60°
最大平面倾角       20°
RANSAC距离门限     0.04 m
RANSAC体素尺寸     0.04 m
最大迭代次数       200
最多候选平面       4
最少剩余点数       100
最少原始内点       60
区域网格尺寸       0.03 m
最小双向跨度       4格，约0.12 m
最少占用网格       12格，约0.0108 m²
95%残差门限        0.05 m
```

这些参数是高速风机底面检测的初始值，需要根据真实风机点数、距离、表面结构和误报情况重新标定。

## 实时策略

订阅队列深度为1，只保留最新一帧，避免RANSAC耗时波动造成旧帧积压。雷达为10 Hz时，单帧时间预算为100 ms。建议实测`processing_time_ms`的平均值小于50 ms，95%分位数小于80 ms。
