# data_recorder

状态：未实现

核对日期：2026-08-06

该目录目前只有职责说明，没有 ROS 2 包、记录节点或任务数据格式实现。

目标职责包括：

- 保存任务元数据、软件版本、配置和标定快照；
- 记录 RTK、IMU、里程计、诊断和结构化净空结果；
- 使用有界异步队列，避免写盘阻塞实时回调；
- 管理任务目录完整、异常终止和恢复标记；
- 后续按存储条件支持 `telemetry_only` 和 `full_raw`。

当前后端的 TXT 下载接口使用固定模拟文件，只验证浏览器下载链路，不属于
`data_recorder` 实现，也不能作为正式记录格式。
